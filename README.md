# DevPulse Tools – Free Web & Network Diagnostics Suite

A modern, lightning-fast suite of developer utilities and network lookup tools designed to rank for high-volume search queries on Google.

## Live Tools Included
1. **IP & ASN Geolocation Lookup** (`ip-lookup.html`)
   - Queries IP location, ASN, ISP organization, coordinates, and reverse DNS.
   - Live interactive OpenStreetMap embed.
2. **DNS Record Inspector** (`dns-lookup.html`)
   - Queries live A, AAAA, MX, TXT, CNAME, NS, SOA records via Google & Cloudflare DNS-over-HTTPS (DoH).
3. **HTTP Security Headers Checker** (`http-headers.html`)
   - Audits HSTS, CSP, X-Frame-Options, Permissions-Policy, and outputs hardened configurations.
4. **JWT Token Decoder** (`jwt-decoder.html`)
   - 100% client-side decoding of JSON Web Tokens, claims inspection, and expiry countdown.
5. **JSON Formatter & Validator** (`json-formatter.html`)
   - Beautifier, minifier, and real-time syntax error highlighter.
6. **SEO & Social Meta Tag Generator** (`meta-tag-generator.html`)
   - Live Google search snippet and Open Graph / Twitter Card previewer.
7. **User-Agent & Device Analyzer** (`user-agent.html`)
   - Hardware detection, WebGL GPU renderer, screen resolution, and fingerprinting info.
8. **Secure Password Generator** (`password-generator.html`)
   - High-entropy cryptographic password generator using `window.crypto.getRandomValues`.

## SEO & Monetization Architecture
- **Schema.org Structured Data**: Included on every tool page (`WebApplication`, `WebSite`).
- **Google AdSense Ready**: Dedicated responsive leaderboard, in-content, and sticky ad placeholders.
- **Fast Core Web Vitals**: Zero bulky frameworks, sub-100ms load times, mobile-optimized.
- **Sitemap & Robots**: Full `sitemap.xml` and `robots.txt` included.
