Common DNS Record Types Explained

  • A Record: Maps a domain name to an IPv4 address.
  • AAAA Record: Maps a domain name to an IPv6 address.
  • MX Record (Mail Exchange): Directs incoming emails to mail servers for that domain.
  • TXT Record: Carries arbitrary text used for SPF email authentication, DKIM, and site verification.
  • CNAME (Canonical Name): Aliases one domain name to another domain.
  • NS (Name Server): Specifies the authoritative DNS servers for the domain.
