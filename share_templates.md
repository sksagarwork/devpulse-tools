Hey everyone,

Whenever I needed to quickly decode a JWT, inspect DNS records via DoH, or format messy JSON, existing sites were loaded with cookie popups, trackers, and took seconds to load.

I created **DevPulse Tools**: a collection of free, lightning-fast utilities that run 100% in your local browser sandbox:

- **IP & ASN Geolocation**: Instant routing & reverse DNS lookup with live OpenStreetMap
- **DNS Record Inspector**: Queries live records (A, AAAA, MX, TXT, NS, SOA) via DNS-over-HTTPS
- **JWT Token Decoder**: Decodes payload claims & expiry timestamps completely client-side
- **Base64 & URL Encoders**: Zero-latency binary/text string converters
- **Cryptographic Hash Gen**: SHA-256, SHA-512, and SHA-1 using native Web Crypto API
- **UUID v4 Generator**: Single or bulk random RFC-4122 keys
- **Security Headers Checker**: Generates hardened HSTS, CSP, and X-Frame-Options configs
- **JSON Validator**: Pinpoints syntax errors with exact line & column numbers

Live link: https://sksagarwork.github.io/devpulse-tools/
Source code: https://github.com/sksagarwork/devpulse-tools

No login, no cookies, and completely free. Would love to hear what other developer utilities you'd like to see added!
